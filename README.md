# # Sephora products 데이터셋 샘플

<h2>1001개의 Sephora 제품 샘플 データセット</h2>

![Sephora products dataset header](https://github.com/luminati-io/Google-Shopping-dataset-sample/blob/main/Google-Shopping-datasets.png)

1000개 이상의 레코드로 구성된 Sephora 제품 データセット 샘플입니다. データセット은 <b>Bright Data API</b>를 사용하여 추출되었습니다.

<h2>Sephora 제품 データセット에 포함된 일부 데이터 포인트:</h2>

* ```url```: 제품 페이지의 URL 또는 링크  
* ```id```: 제품의 고유 식별자  
* ```name```: 제품의 이름 또는 제목  
* ```sku```: 재고 관리 단위(Stock Keeping Unit) 또는 제품과 연관된 고유 식별자  
* ```in_stock```: 제품이 현재 재고가 있는지 여부를 나타냅니다(불리언: True/False)  
* ```regular_price```: 제품의 정가 또는 원래 가격  
* ```actual_price```: 제품의 현재 또는 실제 가격  
* ```unit_price```: 단위당 가격  
* ```value_price```: 제품의 가치 가격 또는 할인 가격  
* ```currency```: 가격이 표시되는 통화  
* ```brand```: 제품과 연관된 브랜드 또는 브랜드명  
* ```images```: 제품과 연관된 이미지  
* ```videos```: 제품과 연관된 동영상  
* ```rating```: 고객이 제품에 부여한 평균 평점  
* ```tags```: 제품과 연관된 태그 또는 라벨  
* ```loyalty_points```: 제품과 연관된 로열티 포인트  
* ```delivery_options```: 제품 배송과 관련된 옵션 또는 정보  
* ```breadcrumbs```: 웹사이트 구조 내에서 제품의 위치를 나타내는 브레드크럼 경로  
* ```promotions_eligible```: 제품이 프로모션 대상인지 여부를 나타냅니다(불리언: True/False)  
* ```variants```: 제품 옵션(variants)에 대한 정보  
* ```description```: 제품의 텍스트 설명  
* ```tips```: 제품에 대한 팁 또는 사용 권장 사항  
* ```more_information```: 제품에 대한 추가 정보  
* ```ingredients```: 제품에 사용된 성분(ingredients)에 대한 정보  
* ```notes```: 제품에 대한 추가 메모 또는 세부 정보  
* ```recommendation_products```: 현재 제품과 함께 추천되는 제품  
* ```product_sku_name```: 제품 SKU 이름  

그 외에도 더 많은 항목이 있습니다.

이는 "Sephora products" データセット에서 파생된 샘플 서브셋이며, 해당 データセット에는 <b>89K개 이상의 레코드</b>가 포함되어 있습니다.

사용 가능한 データセット 파일 형식: <b>JSON, NDJSON, JSON Lines, CSV, 또는 Parquet. 선택적으로 파일을 .gz로 압축할 수 있습니다</b>.

データセット 전달 방식 옵션: <b>Email, API download, Webhook, Amazon S3, Google Cloud storage, Google Cloud PubSub, Microsoft Azure, Snowflake, SFTP</b>.

업데이트 빈도: <b>Once, Daily, Weekly, Monthly, Quarterly, 또는 Custom basis</b>.

추출된 데이터 포인트에 대한 추가 옵션으로 제공되는 데이터 강화(Data enrichment): <b>요청 기반.</b>

<b>[전체 Sephora 제품 データセット 받기](https://brightdata.co.kr/products/datasets/sephora)</b>.

<h2>Sephora 제품 データセット의 활용 사례는 무엇입니까?</h2>

<h3>1. 가격 전략</h3>
Sephora의 유사 제품 및 카테고리를 경쟁사와 정렬하여 가격 전략을 수립하고 동적 가격 책정 모델을 구현합니다.

<h3>2. 제품 재고</h3>
Sephora의 제품 재고에서의 공백을 파악하고, 특정 제품에 대한 수요 증가를 분석하며, 소비자 사이에서 트렌드인 제품을 추적합니다.

<h3>3. 시장 전략</h3>
Sephora データセット을 활용하여 시장 전략 분석을 수행하고, 주요 트렌드를 도출하며, 고객 선호도를 파악합니다.
